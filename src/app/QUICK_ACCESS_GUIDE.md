# ⚡ Quick Access Guide - Input Cost & Expense Tracking

## 🎯 3-Second Access

```
Producer AI Dashboard → Click "💰 Costs" Tab → ✨ Full System Ready
```

## 📊 What You Get Instantly

- ✅ **Daily Summary** - 4 cards showing today's costs, expenses, income, profit
- ✅ **Input Costs Table** - All purchases with editable usage tracking
- ✅ **Activity Expenses** - All farming activities with linked inputs
- ✅ **Grok AI Monitoring** - Real-time fraud detection alerts

## 🚀 Common Tasks (Quick Clicks)

### Add Purchase (30 seconds)
```
1. Click "Add Input Purchase"
2. Fill: Product, Qty, Price
3. Upload invoice (optional)
4. Click "Add with Grok Check"
✅ Done!
```

### Update Usage (10 seconds)
```
1. Click on qty in table
2. Type new number
3. Click ✓
✅ Auto-calculates remaining!
```

### Add Activity (45 seconds)
```
1. Click "Add Activity Expense"
2. Name activity, select type
3. Click "Show Related Inputs"
4. Check boxes for inputs used
5. Enter costs
6. Click "Add with Grok Check"
✅ Linked to inputs!
```

### Record Sale (20 seconds)
```
1. On Sales Income card, click "Add Sale"
2. Fill: Crop, Qty, Price, Buyer
3. Click "Add Sale"
✅ Profit updates!
```

## 📱 Mobile Quick Tips

## 🆘 Quick Fixes

**Problem:** Can't find upload button  
**Fix:** Look in each table row's Actions column

**Problem:** Total showing wrong  
**Fix:** Check date filter at top

**Problem:** Can't edit qty  
**Fix:** Click directly on the number

**Problem:** Related inputs empty  
**Fix:** Click "Show Related Inputs" button
