## 💬 Conversation Examples

### Example 1: Producer Adding Produce

**User:** "How do I add new produce?"

**AI Response:**
```
To add new produce to TRADIE:

1. Click the "Add New Produce" button on your dashboard
2. Select the commodity type (wheat, rice, vegetables, etc.)
3. Enter quantity and quality grade
4. Upload quality certificates if available
5. Set your asking price
6. Submit for verification

Your listing will be live once approved (usually within 24 hours). 
Would you like help with any specific step?
```

### Example 2: KYC Verification

**User:** "What documents do I need for KYC?"

**AI Response:**
```
For Producer KYC verification, you'll need:

📄 Required Documents:
• Government-issued ID (Aadhaar/PAN)
• Address proof
• Land ownership documents
• Farming certificates

The process takes 2-3 business days. You can track your status 
in the "Profile & Security Settings" section. 

Need help uploading documents?
```

### Example 3: Market Prices

**User:** "What are current wheat prices?"

**AI Response:**
```
📊 Current Market Insights:

You can view real-time commodity prices in the "Market Trends" tab. 
Prices are updated every 4 hours from major mandis.

For Producers, I recommend:
• Check daily price trends before listing
• Set competitive prices based on quality grade
• Use the price alert feature for your commodities

Would you like me to explain how to set up price alerts?
```

### Example 4: Payment Tracking

**User:** "When will I get paid?"

**AI Response:**
```
💰 Payment Information:

As a Producer, you can:
• Track payments in the "Payments Received" section
• Request payment for completed orders
• View transaction history
• Download payment receipts

Payments are processed within 24-48 hours after delivery 
confirmation. Need help with a specific transaction?
```

## 🎨 Role-Based Responses

### Same Question, Different Roles

**Question:** "How do I place an order?"

**Producer Role:**
```
As a Producer, you typically receive orders rather than place them. 
However, if you need to purchase inputs:

1. Go to "Marketplace"
2. Browse available products
3. Select quantity and quality
4. Submit purchase request

For selling your produce, customers will place orders with you. 
Would you like to know how to manage incoming orders?
```

**Trader Role:**
```
As a Trader, to place bulk orders:

1. Go to "Marketplace" → "Bulk Orders"
2. Search for commodity and specifications
3. Filter by region, quality, quantity
4. Request quotes from multiple suppliers
5. Compare and select best offer
6. Place order with payment terms

You can also set up standing orders for regular procurement. 
Need help with credit facilities?
```

**Buyer Role:**
```
As a Buyer, to place an order:

1. Browse produce listings
2. Check quality certifications
3. Select quantity needed
4. Choose delivery options
5. Add to cart
6. Complete payment

You'll receive order confirmation and tracking details. 
Quality verification is available before final payment. 
Would you like to know about delivery options?
```
