## 🐛 **Troubleshooting**

### **Issue: Button Not Showing**
```bash
# Clear cache and restart
rm -rf node_modules/.cache
npm run dev
```

### **Issue: No Animations**
Check imports:
```typescript
import { motion, AnimatePresence } from 'motion/react';
```

### **Issue: White Screen**
Check browser console for errors:
- Missing imports?
- Component syntax error?
- Route not registered?

### **Issue: Icons Missing**
Verify lucide-react:
```typescript
import { Coins, Sparkles, Leaf } from 'lucide-react';
```
