## 👥 Team Member Management

### **Adding Team Members**

**Prerequisites:**
- Must have Marketing & Procurement role
- Maximum 5 members allowed
- Each needs consent via OTP

**Process:**

1. **Enter Member Details**
   - Full name
   - Mobile number (10 digits)
   - Click "Add Member"

2. **OTP Verification**
   - System sends OTP to member's mobile
   - Member enters 6-digit code
   - Verification confirms consent
   - Member added to team

3. **Member Appears in List**
   - Green checkmark badge
   - Shows name & mobile
   - Can be removed anytime

**Team Member Permissions:**
- Access shared dashboard
- View producer listings
- Execute trades (if authorized)
- Track commission splits
- View team analytics

## 🔐 Security & Verification

### **OTP Verification**

**When Required:**
- Adding team members
- Member consent confirmation
- Phone number verification

**Process:**
1. User enters member mobile
2. System sends 6-digit OTP
3. Member receives SMS
4. Member enters OTP
5. System verifies code
6. Member added to team

**Security:**
- Ensures member consent
- Prevents unauthorized addition
- Validates phone numbers
- Audit trail maintained
