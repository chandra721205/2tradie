## 🎯 Pro Tips

### For Storage Selection

**Tip 1**: Look for "Qualified Producers" badge
- Means you get special advantages
- Usually 10-15% discount
- Priority booking

**Tip 2**: Check "Last Updated" on compliance
- Fresh certifications = reliable facility
- Old dates = ask agent to verify

**Tip 3**: Use "Assign Agent" for first-time storage
- They'll explain everything
- Help with paperwork
- Often get better rates for you

### For Selling

**Tip 4**: Read AI Insights BEFORE choosing sell path
- If "prices rising" → Store first
- If "demand high today" → Direct sale
- If "agent can get premium" → Use commission agent

**Tip 5**: Commission agents worth it when:
- Commodity value > ₹50,000
- Market price volatile
- You want best negotiation
- Commission < 3%

**Tip 6**: Direct sale best when:
- Perishable commodities
- Need money immediately
- Local demand high
- Small quantities

### For Agent Selection

**Tip 7**: Match agent specialization to your need
- Cold storage → Rajesh Kumar
- Farm/Silo → Meena Patel
- General warehouse → Harpreet Singh

**Tip 8**: Language matters
- Choose agent who speaks your language
- Communication is key
- Prevents misunderstandings

**Tip 9**: Check response time
- Urgent? → Pick fastest responder
- Planning ahead? → Any agent fine

## 🆘 Troubleshooting

### Problem: No facilities showing
**Solution**:
1. Clear search box
2. Reset all filters (click "Reset")
3. Try broader storage type

### Problem: All agents busy
**Solution**:
1. Check agent cards for "Available tomorrow"
2. Leave a request (coming soon)
3. Contact support for urgent help

### Problem: Can't decide which sell path
**Solution**:
1. Go to AI Insights tab first
2. Read market predictions
3. OR click "Assign Sales Agent" - they'll advise!

### Problem: Facility details not loading
**Solution**:
1. Click card again to refresh
2. Try different facility
3. Check internet connection
