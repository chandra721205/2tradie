## 💬 Request Service (30 sec)

```
1. Click "Request" button on provider card
2. Fill form:
   - Description of work
   - Your location
   - Start date (+ end date)
   - Budget
   - Urgency (Low/Medium/High)
3. Click "Send Request"
4. Provider contacts you within stated response time
```

## ➕ Add Provider (2 min)

```
1. Click "Add Provider" button
2. Fill details:
   - Provider name
   - Category & subcategory
   - Location
   - Contact (phone/email)
   - Services offered
   - Description
   - Experience & pricing
3. Submit for review
4. Get approved in 2-3 days
```

## 🎯 Common Use Cases

### Hiring Labor for Harvest:
1. Go to "Labor Services" tab
2. Filter: Available + Your district
3. Look for "Unskilled Labor" or "Labor Associations"
4. Check rating > 4.0
5. Request with dates and headcount

### Renting Harvester:
1. Go to "Equipment Rental" tab
2. Search "harvester"
3. Filter by price and availability
4. Check available dates
5. Request for your timeline

### Booking Borewell Drilling:
1. Go to "Borewell & Irrigation" tab
2. Look for "Drilling Contractors"
3. Check certifications (CGWA)
4. Compare prices (per foot)
5. Request with location details

### Hiring Drone Service:
1. Go to "Drone & Aerial Services" tab
2. Choose "Crop Monitoring"
3. Check certifications (DGCA)
4. Review per-acre pricing
5. Request with farm size

## 💡 Pro Tips

1. **Book Early:** During peak seasons, book 2-3 weeks ahead
2. **Check Reviews:** Always read recent reviews
3. **Verify Contact:** Call before sending request
4. **Compare Prices:** Check 3-4 providers
5. **Read Description:** Understand what's included
6. **Check Distance:** Closer = lower travel costs
7. **Verify Licenses:** For technical services
8. **Use Filters:** Save time with smart filtering

## 🆘 Troubleshooting

**No providers found:**
- Clear filters
- Expand search radius
- Try different category

**Request not sent:**
- Check internet connection
- Fill all required fields
- Verify budget amount

**Can't contact provider:**
- Use "Request" button instead
- Try WhatsApp if available
- Check phone number format
